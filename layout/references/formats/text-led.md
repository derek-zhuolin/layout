# 无图排版参考：收紧关系，增加有用的层次

这是 2026-10-24 一次用户确认的纯文字版修改中提炼的方法，适用于「文字够了，但标题、说明和内容块彼此太远」的情况。它是可选构图参考，不是每次调用必套的模板。无图指没有本次内容照片或截图；可以按语义加入手绘 icon，也可以完全不用图标。

## 这次解决了什么

原稿的标题、说明和几个并列话题各自成组，但组间空白过大，读起来像三段互不相连的内容。修改保留全部文案与字号重点，收紧组间距离，把小卡从单行标签改成「相关手绘 icon + 原标签」，再用浅底和轻投影连接起来。

有效的不是固定坐标或增加装饰数量，而是让同一个主题形成连贯的阅读区域。外边距仍可留白，不需要把整张纸填满。

## 可借用的三个手法

1. **先收紧关系。** 标题与它的说明靠近；说明后紧接对应的小卡或列表。先移动内容组、调整断行和组内外间距，不先缩小文字、删内容或用装饰填空。缩到手机尺寸看，读者能否自然从标题读到说明，再读到相关内容？
2. **图标解释标签。** 有真实并列项目时，可给小卡放语义相关的 Oreo Design 手绘 icon。比如需求/场景可选 notebook，内容组织可选 layers，电脑动手可选 laptop。具体含义以本篇为准，不把这三个图标写死。沿用原 SVG 路径、viewBox 和许可，通过 currentColor 配蓝色；没有合适图标就省略，不增加虚构话题凑卡片。
3. **用层次表现分组。** 纸白画布上可放一层浅灰蓝分组，再放白色内容小卡；icon 可有柔和的浅蓝底座、轻内阴影。必要时增加轻微错位的衬纸。卡片文字保持水平，阴影方向一致，图标与文字之间留出可读间距。不是每组都要叠满这些层。

小卡图标承担内容识别，不与纯装饰混为固定数量配额。它们不能挤压标题和正文；手机上看不清时，优先调整构图或简化底座。

## 按内容变化，不锁版式

| 当前内容 | 可考虑的组织方式 |
|---|---|
| 一句个人表达 | 用断行、字号、位置完成主视觉；不必加卡片或 icon |
| 标题 + 说明 + 几项并列内容 | 参考本次紧密分组与图标小卡；卡片数量、列数由内容和比例决定 |
| 连续论述或较长解释 | 用段落、窄栏或小标题组织，不硬拆成相同大小的卡片 |
| 有先后关系的步骤 | 使用顺序明确的流程布局，不能只套并列卡片 |
| 横版 deck 或其他比例 | 重新组织标题、说明与内容区域，可左右分区；不沿用竖版绝对坐标 |

标题可以居中、靠左或与内容分栏。无需每次使用大蓝字、手绘下划线、三块小卡、图标底座和叠纸。品牌、Logo、作者署名、角标与页码仍按本次开关决定，默认关闭。案例里的联名名称、城市、文案和事实不作为新稿默认值。

## 怎么判断这次改对了

- 同一主题的几组内容看起来有关联，空白有阅读作用；既不松散，也没有挤成一团。
- 主标题仍最先被看到，说明和标签在实际查看尺寸下可读，内容和必要限定没有被删。
- 图标与小卡含义对应，卡片层次帮助分组；没有无关装饰、空槽或强加的品牌。
- 先看缩略图的主次，再放大看文字与 icon；间距、字号、卡片数均不作为统一通过阈值。
- 用户只改某一版时，仅调整该版及必要共用依赖；已确认照片版保留。必要时用图片哈希和渲染对比核对局部修改范围。

这些是复核问题，不是完整性之外的新门槛。其他排版同样能满足内容、阅读和本篇审美时，不因为未采用本例而重做。
