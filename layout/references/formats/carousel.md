# 轮播图排版

竖版卡片包括3:4与9:16，默认3:4，每页一个重点；图上简短，正文承载细节。居中封面、左文右图、图片先行、经典左上、左图右文、下沉收尾可交错使用，不锁住所有标题的位置。

标题和说明紧密成组；相关卡片用浅底分组，不用厚阴影和无关图标填空。主标题周围保留空间，但主题内部不能断成很远的几块。约96px以上横向空带需肉眼复核，不作为机械失败阈值。

文字与对应小标题16–32px、内部20–40px为起点。相纸可轻倾2–3°，正文保持水平。照片保留原色、身份与真实来源，往期注明往期。

比例更换见aspect-ratios.md；3:4不是固定六页配额。示例的标题、照片、故事和观点不自动进入新稿。

9:16采用1080×1920逻辑画布，默认2倍导出。保持可读字号，重新安排标题和纵向步骤；不要给3:4简单增加一块空白，也不要把原图拉长。流程卡之间留间隔，总结紧随流程。不默认添加装饰性大引号。

有合适图先用独立相纸窗口，标题与图分区；位置按内容变化。无图时不留相框，完成文字构图。每页一个主重点不等于只能有一句话，必要证据与限定条件应保留。页眉、页脚、栏目角标和页码默认不显示；明确启用后再安排空间。
