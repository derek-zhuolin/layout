# 标准、可配置与每篇判断

标准化：来源、原文保真、字体加载、版本、导出、交付、文字同步与越界检查。

可配置：carousel/deck、3:4/9:16/16:9/4:3、作者语气、署名、logo、照片与页数。蓝白黑是本Skill默认，不因换比例自行换配色。

每篇独有：喜欢谁的原因、事实数字、是否值得、个人经历、未知与期待。由当前作者和材料提供，不从案例推定。

公开模板前三类使用合成文案；图文素材板与真实案例页使用经确认的现场图片，仅用于本项目展示。个人原稿不公开。新项目换用自己的素材，发布须有当前请求授权。

新稿默认：图片状态先确认，photo=null；brand/logo/author/cornerLabel/pageNumber 全部关闭。明确提供并要求使用才启用。页面主体需要出现的公司/活动名称或来源注释，不属于装饰角标，不机械删除。

新稿从 assets/starter 创建，案例从 assets/playground 与 assets/approved-cases 查看，两条路径分开。普通用户无需选择作者档案；私有档案只在当前作者适用，不改变新稿品牌默认值。
