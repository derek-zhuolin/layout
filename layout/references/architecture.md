# 架构

SKILL.md：目标、第一步素材 Todo、编辑权限、比例、默认构图与按需路由。

- references/standards：素材确认、生产、文本保真，以及按风险分层的验收。
- references/formats：轮播/deck 与比例重排。
- references/profiles：品牌独立的默认视觉、可替换语气与配置边界。
- assets/starter：无品牌起稿入口，图片与角标默认关闭，不引用案例图。
- assets/playground、assets/approved-cases：带说明的参考展示，不能直接作为新项目默认内容。
- scripts/new-project.py：复制起稿所需依赖，选填本次指定照片；其余 scripts 负责案例导出与确定性检查。

公开包不包含私人原稿、原始照片或本机配置。参考案例中已有用户确认可公开的成图，保留来源与展示许可边界。个人安装可保留私有作者档案，不能默认发布。

参考 Codex Skill 的聚焦职责与按需加载：https://developers.openai.com/codex/skills 。机器检查不替代审美、内容完整性与作者语气判断，不因每项清单都「打勾」增加无用内容。
