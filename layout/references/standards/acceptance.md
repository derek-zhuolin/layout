# 验收：守住内容，不让检查替代设计

检查用于发现真实缺陷，不追求每页满足同一套外观。只运行与本次改动有关的检查；规则没有实际帮助时说明取舍，不为了「全绿」删内容、缩字或添装饰。

## 1. 必须修复：正确性与可用性

- 本次素材已查看，或明确记录无图/未解决；不能把打不开、没找到、未回复写成无图。不能借用参考案例照片冒充本次素材。
- 关键观点、证据与限定条件没有丢失；事实不编造，往期与本次不混淆。编辑权限与交付载体符合本次要求。
- 品牌、Logo、署名、栏目角标与页码无授权默认不显示，不占空位；来源图注、必要正文名称与 Reference 不误删。
- 文字不被裁切、遮住或缩到不可读；关键图片主体/截图证据不丢失。图片、字体真实加载，损坏图片不能伪装成空白设计。
- 导出格式、顺序、尺寸与预览一致；相对资源可用。不能把占位信息、加载失败或待确认事实作为可发布最终稿。
- 私人绝对路径、凭证与无关素材不进入公开包；真实来源与许可保留。原文锁定任务逐字节同步，不能偷偷改字。

## 2. 需要视觉复核：优先修构图

- 重点在手机/投屏尺寸是否能读到？正文重要条件有没有为了短句而丢失？
- 图片是否解释了内容，还是只占空间？图片与文字互相抢视线吗？有图优先独立窗口，不强制所有页有图。
- 主次、间距和浅底分组是否帮助理解？空白是否有阅读作用？太空可扩大主体/收紧关系，拥挤可重排/拆页。
- 相纸、轻阴影、图标与胶带是否有明确作用？截图、表格、密集文字保持清楚，不强行倾斜。
- 整组阅读顺序是否自然？标题位置可以变化，但不要求轮换固定次数。重复构图若帮助对照，可以保留。
- 每种比例重新组织信息；不能把竖版截图当成横版重排。按内容选择列数，不设固定卡片配额。

字号、行数、间距、图片占比、页数、点缀数都是起点，不能作为机械否决条件。一页一个主重点可以包含事实、证据和必要条件。内容放不下：先调整构图/拆页/补充附页；移动到正文时保留理解所需信息，锁定文字不擅自省略。

## 3. 可选增强：不阻断完成

粘土底座、纸夹、胶带、额外 icon、复杂过渡、更多比例、原生可编辑 PPTX 等，仅在有用或用户要求时加入。没有装饰、没有照片、没有角标本身都不是缺陷。不存在真实引用时不加装饰性双引号。

## 回归场景（按本次影响选取）

| 输入或变化 | 应有行为 | 要防止的失败 |
|---|---|---|
| 已附一张真实照片 | 先看图，选适合的窗口与裁切 | 忽略附件、又要求上传 |
| 「桌面某活动目录里的合照」 | 按限定目录定位并查看；唯一匹配直接用 | 要求用户手输绝对路径、全盘扫图 |
| 目录中多张相近照片 | 给少量候选，确认当前选择 | 仅凭文件名认定身份/活动 |
| 路径失效或读取失败 | 说明阻碍，可继续独立文字工作 | 静默当无图、偷换案例图 |
| 完全没给图片 | 合并问一次图片/路径/口述线索 | 跳过询问、留下大空框 |
| 明确只要文字 | 直接完成有层次的文字版 | 反复要图、生成假现场 |
| 只给风格参考截图 | 学构图，区分内容素材 | 把参考海报当作本次成品素材 |
| 横图/竖图/多人合照 | 重排窗口，主体完整可读 | 强裁人脸、统一拉伸 |
| 模糊图或与内容无关的图 | 说明限制，选择局部/替代/文字方案 | 图片优先变成硬塞弱图 |
| 图表或产品截图 | 水平清晰，必要局部放大 | 倾斜缩小到无法阅读 |
| 新作者、不提供品牌 | 无品牌/角标/署名/页码且无空槽 | 默认出现参考品牌或 Layout 标识 |
| 明确提供自己的品牌 | 仅显示本次启用字段 | 夹带旧品牌、强加其他角标 |
| 标题长、正文含必要条件 | 保留意思，重排或增页 | 为字号/页数配额删关键信息 |
| 很短的原话 | 用字号、断行、位置形成完整画面 | 加空泛金句/无关图标凑满 |
| 「最终原文，不要润色」 | 原样保存到指定载体 | 改标点空格、补 CTA |
| 「只更新正文与下载包」 | 图像哈希不变 | 顺手重做整组图片 |
| 「第2页太空，其他不变」 | 调整该页与必要共用依赖 | 换全套配色/无意义批量重排 |
| 3:4 改为 9:16/横版 | 重排阅读关系与图文窗口 | 拉伸旧稿或增加空白凑尺寸 |

## 验证与记录的边界

机器可检查链接、JSON、品牌开关、未引用案例、素材加载、边界与导出；判断不到「内容是否动人」或图片与观点是否贴合。写清已跑的场景、只做规则审阅的场景和仍需用户看的部分。不要把场景清单当成已完成的独立 Agent 评测，不为 Markdown 规则启动批量模型任务。

新稿骨架：`node scripts/verify-starter.cjs <仓库目录>` 检查四比例下无品牌文字版与显式选图窗口、品牌开启、正文转义及图片失败状态。公开展示页改动才运行 `smoke-site.cjs`，不用每次文案修改都重测全站。

原文同步任务另按 text-sync.md 验证：source/txt/ZIP 字节相等、HTML 解码相等；只改正文 PNG 哈希不变。ZIP 可解压，字体、图片尺寸、文字边界与实际交付对应。渲染通过、人工目视通过、用户已认可分别记录。
