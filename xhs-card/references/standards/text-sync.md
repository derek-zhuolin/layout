# 定稿原文同步

触发：用户说“这是我的最终版、原文同步、不要润色”。目标是保真，不是提升语言质量。

1. 将用户明确选中的正文单独保存为 UTF-8 原文；不把后面的操作要求一起存入。没有标题就不加标题；不规范化标点、空格、换行、英文大小写，不附 Markdown 星号。
2. 以该原文作为唯一输入。原文文件和发布 txt/ZIP 内的 txt 应字节一致。HTML 展示只做必要字符转义，解码后文字必须一致。
3. 预览页若含正文、生成脚本若嵌入正文、已有下载包若含正文，全部同步。先备份旧正文。其他图片与源材料不动，除非用户要求。
4. 已知适配器：`python3 <SKILL_DIR>/scripts/sync-final-copy.py --source <原文.txt> --project <目录> --archive <包名.zip>`。默认目标 `小红书最终正文.txt`；适配本项目 `index.html` / `preview.cjs` 的 `textarea#postText`。陌生页面结构先检查并适配，不盲目替换。
5. 脚本记录锁定 SHA256 与图片 SHA256；检查源文件、txt、HTML 解码内容、ZIP 原文字节一致。随后只刷新需要的页面截图，不重导图片。若事实存疑，另外提示，不能静默修改锁定原文。

85%—90% 保留尺度仅用于 light-edit；verbatim 的标准为 100% 保留原文。锁定后新的明确修改请求可以更新定稿，不能擅自解锁。
