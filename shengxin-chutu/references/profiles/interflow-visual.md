# 互通有无视觉档案（可替换配置）

以下按 1080×1440 逻辑画布；2 倍导出。参数是可复用起点，不把新文案塞进旧坐标。

## 颜色、字体与网格

| 角色 | 参数 |
|---|---|
| 底纸 / 字 / 主蓝 | #FCFCFA / #191B1E / #0873D3 |
| 浅色分组 / 标签 / 描边 | #E4EEF5 / #C5E3FA / #DBE0E3 |
| 重点深蓝（可选） | #0C3971，仅单个重点区 |
| 字体 | Source Han Sans SC，Regular 400、Medium 500–600、Bold 700 |
| 主标题 | 72–84px，分栏可 66–76px，行高 1.23–1.35，按语意断 2–3 行 |
| 重点句 / 正文 | 38–50px / 26–31px，正文行高约 1.5–1.7 |
| 卡片标题 / 短注 | 29–33px / 20–23px，短注不承载主要观点 |
| 来源、页脚 | 15–18px，只放次要内容 |
| 左右安全边距 | 64px；顶部页眉约 47px；页脚区固定在底部 |
| 间距起点 | 16 / 20 / 24 / 32 / 40px；相关内容内部紧，组间稍松 |

英文和数字也用思源黑体；原始 logo 不改。等字体及图片加载完成再导出。手机宽度下若主信息太小，减少内容或换构图，不缩字硬塞。白底为主，一页通常只设一个高对比蓝色区。照片不套蓝色滤镜。

## 层次：纸底 → 分组 → 内容 → 小点缀

| 层 | 处理 | 用途 |
|---|---|---|
| 0 底纸 | 纸白、无重纹理 | 阅读背景 |
| 1 分组 | 浅灰蓝或白容器，18–24px 圆角，1px 淡描边 | 将相关步骤/问题聚在一起 |
| 2 内容卡 | 白相纸、便签、票卡，12–18px 圆角、轻阴影 | 形成主体前后关系 |
| 3 点缀 | 语义图标、纸夹、胶带、小标签，少量局部重叠 | 增加手绘笔记感 |

不是每页都要四层齐全。阴影同向：卡片 `0 9px 22px #15324e10`，照片 `0 16px 32px #15324e15`。相纸边约 13px；照片/小卡倾斜 2–3 度，局部标签可略多；长正文和密集列表保持水平。每页约 1–2 处点缀，不盖文字与人脸。

默认“轻浮起”。Playground 的“平面/纸片叠放”是对比选项，不自动把全部作品改成厚投影。轻粘土质感可作局部点缀，具体用法见下节；Doodle 仍是主要语义图标，不自动恢复整套 3D 芯片/机器人。

可复用组合：相纸+胶带、浅底+三步骤卡、窗口+实拍、照片+窄纸条、票卡+虚线分组。窗口是排版容器，不能冒充软件操作证据；票卡不能伪装成已领取的优惠凭证。

## 轻粘土质感：局部、柔软、克制

保留用户早期参考里的圆润边缘、软投影和一点厚度，用在小卡、图标底座或标签上。每页通常 0–1 个重点，其他内容维持清楚的纸卡层次；不把整页变成 3D 插画。

- 颜色仍用蓝白黑与浅蓝，不引入彩虹渐变、金属或玻璃材质。
- 光从左上来，投影向右下；用浅色上缘与略暗下缘表现厚度。阴影应贴近物件，不能像悬空大黑块。
- 手绘 icon 保持原来的线条，可落在柔软圆角底座上，不把图标本身膨胀成另一套风格。
- CSS 起点（需要视觉复核，不是所有页面强制参数）：`border-radius: 20px; background: #E4EEF5; box-shadow: inset 2px 2px 4px #ffffffb3, inset -2px -3px 5px #15324e0d, 0 7px 14px #15324e12;`。
- 当前随包模板实现的是纸卡和轻浮起阴影；上面的内阴影为可选配方，未声称已套用到现有 PNG。需要新增粘土物件时先做一页看效果，不批量改变已确认成图。

质感参考用于理解柔软边缘和轻微厚度；主图标仍采用 Doodle，不要求照搬某张参考中的物件。

## Doodle Icons

来源 [oreo-design/doodle-icons](https://github.com/oreo-design/doodle-icons) ，随包 `assets/icons/` 保留 MIT LICENSE。沿用原始 SVG 路径和 viewBox，以 currentColor 配色：浅底蓝色，蓝底白/浅蓝。

图标服务语义：想法 bulb，交流 chat/users，电脑实践 laptop/code，修改 pencil/brush，笔记 notebook，完成 check，方向 arrow-right。缺合适图标可不用，不给每个 AI 话题都加机器人。小图标约 40–48px，重点点缀约 60–90px；不拉伸、混库或用 emoji 替代。

图标、字体、logo 的许可随输出源文件保留。新材料的来源单独记录。

## 本地升级中的手绘与纸片组合

保留一页一个主重点。活动页用问题卡、纸夹与一条便签；表达页用想法图标、手绘下划线和短纸条；流程页用胶带固定外层容器、纸签标注分组；图文页用两张实际出图形成素材板。点缀落在模块边缘，不压标题、正文和人脸。

手绘 icon 继续使用随包 Doodle 原 SVG；胶带和手绘下划线由 CSS 构成。多比例分别调整点缀位置，不能把同一组绝对坐标直接缩放。已确认的三张真实成图保持原样，作为源参考。
